# 🧙 Волшебники — Браузерная 2D-аркада

Браузерная 2D-аркада «Волшебники» — игрок против ИИ на одной арене.

## 🚀 Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build
```

После `npm run dev` откройте браузер по адресу, указанному в терминале (обычно `http://localhost:5173`).

После `npm run build` содержимое папки `dist/` можно разместить на любом статическом хостинге.

## 🎯 Геймплей

1. **Собирайте травы** на арене (автоматически при касании)
2. **Подойдите к котлу** и нажмите **F** — откроется интерфейс с рецептами
3. **Выберите рецепт** стрелками ← → (доступны только рецепты с нужными травами)
4. **Приготовьте заклинание** клавишей **Space**
5. **Используйте заклинания** (Space) — атаку, лечение или щит
6. **Победите противника** — снизьте его HP до 0 или наберите больше очков к концу таймера

### Режимы
- **На время** (60 / 120 / 300 секунд) — побеждает тот, у кого больше HP/урона/трав
- **Насмерть** — игра до смерти одного из волшебников

### Рецепты
| Заклинание | Ингредиенты |
|---|---|
| Огненный шар (22 урона) | Огненный цветок ×2, Каменный корень ×1 |
| Ледяная стрела (14 урона) | Лунный лист ×2, Огненный цветок ×1 |
| Исцеление (+25 HP) | Лунный лист ×2, Каменный корень ×1 |
| Щит (4 сек, -50% урона) | Каменный корень ×2, Лунный лист ×1 |

## 🏗️ Архитектура

```
Input Adapters → Simulation (чистый core) → Events → UI / Renderer
                      ↑
                 AI Input (FSM)
```

- **Simulation** — чистый TypeScript, фиксированный шаг 1/60 с, детерминированный RNG (Mulberry32)
- **Renderer** — Canvas 2D, процедурная графика
- **UI** — React (минимальная обёртка), HUD поверх canvas
- **AI** — конечный автомат (FSM) + A* навигация
- **Audio** — Web Audio API, синтез осциллятором

## ⚙️ Настройка баланса

Все параметры в `src/data/*.json`:
- `herbs.json` — типы трав и веса спавна
- `spells.json` — характеристики заклинаний
- `recipes.json` — рецепты крафта
- `ai.json` — параметры ИИ
- `map.json` — карта арены

## 🛠️ Технологии

- TypeScript (strict mode)
- Vite
- Canvas 2D (процедурная графика)
- Web Audio API (синтез звука)
- Gamepad API
- React (только для UI-обёртки)

## ⚠️ Известные ограничения

- Gamepad API может требовать HTTPS или localhost
- Нет сетевой игры
- Один уровень сложности ИИ
- Одна карта
